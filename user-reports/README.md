# user-reports/ — авто-отчёты из приложения

Сюда заливаются отладочные отчёты, отправленные кнопкой **«Отправить отчёт
на GitHub»** на шаге «Анализ» в приложении BikeSnap. Начиная с v1.14.11
кнопка делает три вещи автоматически:

1. Фото каждого ракурса → отдельный файл `user-reports/<дата>/...-photo-<view>.jpg`.
2. JSON отчёта (точки тела, анализ/ошибка, гироскоп, контекст онбординга)
   → `user-reports/<дата>/bikesnap-report-vX.Y.Z-<stamp>.json`
   (в JSON вместо base64-фото — поле `photoFile` со ссылкой на файл выше).
3. Issue со сводкой (версия, статус, ошибки, ссылки на файлы) с меткой
   `auto-report`.

## Протокол работы агента

- Каждая сессия: `python scripts/check-reports.py` — список открытых
  auto-report issue + скачанные сюда новые отчёты.
- Новый отчёт → скачать, проанализировать (фото + точки + ошибки) →
  починить код/алгоритм → ответить в issue выводом и версией фикса →
  закрыть issue.
- Файлы здесь — часть истории репозитория: коммитятся и переживают
  пересборку воркспейса.

## Приватность

Репозиторий открытый: фото велосипедов и данные отчётов видны публично.
Отчёты содержат только велосипеды, точки позы и параметры фита — без
персональных данных пользователя.
